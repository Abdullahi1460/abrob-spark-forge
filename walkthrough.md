# Render Deployment Walkthrough

## Prerequisites
- Your project is now pushed to GitHub on the `main` branch: https://github.com/Abdullahi1460/abrob-spark-forge
- A free Render account (https://render.com) – sign‑up if you don’t have one.

## 1️⃣ Import the repository
1. Log in to Render and click **“New” → “Web Service”**.
2. Choose **“Connect your repository”** and select **GitHub** → the `abrob-spark-forge` repo.
3. Keep the default branch **`main`**.

## 2️⃣ Create the Front‑end Service (Vite static site)
- **Name:** `abrob-frontend`
- **Environment:** `Node`
- **Build Command:** `npm install && npm run build`
- **Start Command:** `npx serve -s dist`  _(Render will serve the `dist` directory generated by Vite)_.
- **Root Directory:** leave blank (project root).
- **Environment Variables:** none required for the static front‑end.

## 3️⃣ Create the Back‑end Service (Node/Express)
- **Name:** `abrob-backend`
- **Environment:** `Node`
- **Build Command:** `npm install`
- **Start Command:** `node backend/server.js`
- **Root Directory:** leave blank.
- **Environment Variables:** add any needed values (e.g., DB connection string) via **“Environment” → “Add Environment Variable”**.  Do **not** commit real secrets; keep them only in Render’s UI.

## 4️⃣ Render `render.yaml` (optional – for autoscaling)
We added a `render.yaml` file at the project root:
```
services:
  - type: web
    name: abrob-frontend
    env: node
    buildCommand: "npm install && npm run build"
    startCommand: "npx serve -s dist"
    repo: https://github.com/Abdullahi1460/abrob-spark-forge.git
    branch: main

  - type: web
    name: abrob-backend
    env: node
    buildCommand: "npm install"
    startCommand: "node backend/server.js"
    repo: https://github.com/Abdullahi1460/abrob-spark-forge.git
    branch: main
```
Render will automatically read this file if you create the services via the **“New Service → From render.yaml”** wizard.

## 5️⃣ Verify the deployment
- After each service is created, Render will start a build.  You can watch the logs in the **Logs** tab.
- Once the build finishes, the **URL** for each service appears (e.g., `https://abrob-frontend.onrender.com`).
- Open the front‑end URL; you should see your ABROB site.  The front‑end can make API calls to the back‑end URL (e.g., `https://abrob-backend.onrender.com/api/...`).

## 6️⃣ Automatic redeploys
- Every push to `main` triggers a new build on both services.  No further action is needed.
- If you need to change environment variables, edit them in the Render dashboard and click **“Restart Service”**.

## 7️⃣ Free‑tier limits to keep in mind
- **Memory:** 512 MiB per service (enough for this small app).
- **CPU:** 1 vCPU shared.
- **Build time:** 15 min per service per deploy.
- **Idle timeout:** Services sleep after 15 min of inactivity; they wake on the next request.

Your ABROB Spark Forge app is now live on Render.  Future changes can be pushed to GitHub and will automatically redeploy.
